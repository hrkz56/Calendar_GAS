# Calendar_GAS Ver1.0 Phase4 Final

## 概要

勤務表テキストを解析し、カテゴリ・登録先カレンダーを選択してGoogleカレンダーへ登録するGoogle Apps Scriptです。

## Phase4で実装済み

- 同一予定の重複チェック
- 重複予定の自動スキップ
- 登録対象カテゴリの選択
- 所有カレンダー一覧の取得
- 登録先カレンダー選択UI
- 月単位削除
- カテゴリ指定削除
- Calendar_GAS作成予定のみを対象とした安全な削除
- 登録・スキップ・失敗件数の表示
- 削除・対象外・失敗件数の表示

## 重複判定条件

以下が一致する予定を重複と判定します。

- タイトル
- 終日／時間指定
- 日付
- 開始時刻
- 終了時刻

## 月単位削除の安全設計

削除対象は次のいずれかでCalendar_GAS作成予定と判定できるものです。

- 説明欄に `カテゴリ:` が記録されている
- タイトルがCalendar_GASの命名規則に一致する

対象カテゴリとして選択されていない予定や、Calendar_GAS作成予定と判定できない予定は削除しません。

## 導入手順

1. Google Apps Scriptで新しいプロジェクトを作成します。
2. ZIP内の各ファイルを同名で作成し、内容を貼り付けます。
3. プロジェクト設定のタイムゾーンを `Asia/Tokyo` に設定します。
4. 初回実行時にGoogleカレンダーへのアクセス権限を承認します。
5. ウェブアプリとしてデプロイします。
6. 発行されたURLを開きます。

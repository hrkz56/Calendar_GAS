# Calendar_GAS Ver1.1

ちゃっぴーカレンダー用のGoogle Apps Script Webアプリです。

## Ver1.1の主な変更

- 登録対象カテゴリのチェック状態と「サンプル入力」を連動。
- カテゴリごとに25色から任意の色をプルダウン選択可能。
- カラー設定はUser Propertiesへ保存し、次回起動時も維持。
- 25色を正確に反映するため、基準カレンダーごと・カテゴリごとに専用カレンダーを必要時に自動作成。
- 専用カレンダー名: `ちゃっぴー｜<基準カレンダー名>｜<カテゴリ>`
- カレンダー色はCalendar APIの`backgroundColor`をRGB指定して反映。
- 既存の基準カレンダー内の予定は移動しない。
- 月単位削除は基準カレンダーとカテゴリ別専用カレンダーを対象にする。

## 初回利用時の注意

Ver1.1ではカレンダー色をRGB指定するため、再デプロイ後の初回利用時にGoogle Calendarおよび外部リクエスト権限の再承認が必要になる場合があります。

## 基本手順

1. Webアプリで基準カレンダーを選択。
2. 登録対象カテゴリを選択。
3. 必要に応じてカテゴリカラーを変更し「カラー設定を保存」。
4. サンプル入力または予定を直接入力。
5. プレビュー後にGoogleカレンダーへ登録。
